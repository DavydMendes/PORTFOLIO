## Descrição do Portfólio
Este projeto consiste no desenvolvimento de um portfólio pessoal responsivo, criado com o objetivo de apresentar a trajetória acadêmica, competências técnicas e principais projetos desenvolvidos.

## Tecnologias Utilizadas

* CSS3
* Bootstrap 5
* Git e GitHub

## Link do Site Publicado
[https://SEU-USUARIO.github.io/portfolio/](https://SEU-USUARIO.github.io/portfolio/)

## Explicação do Funcionamento do Projeto
O site utiliza uma estrutura de página única (*Single Page Application*) com navegação interna fluida por meio de um menu superior fixo. Contém seções de Apresentação (Perfil), Vitrine de Projetos, Habilidades Técnicas e Contato.

## Descrição do Recurso Novo Adicionado
Foi implementado um efeito visual de animação interativa nos elementos de cards e blocos de habilidades utilizando transições CSS (`transform: translateY` e sombras dinâmicas no `:hover`).

## Explicação de Como Esse Recurso Foi Implementado
O efeito foi programado no arquivo `style.css` utilizando a propriedade `transition` combinada com o seletor `:hover`, garantindo que os elementos ganhem destaque visual imediato e fluidez ao receberem o ponteiro do mouse.
